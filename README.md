# YelpCamp 🏕️

YelpCamp is a full-stack web application that allows users to discover, create, and review campgrounds.
The project was built to practice real-world backend and full-stack concepts such as authentication,
authorization, RESTful routing, and database relationships.

---

## 🚀 Features

- User authentication and authorization
- Create, edit, and delete campgrounds
- Add and manage reviews
- Image uploads with Cloudinary
- Interactive maps using Mapbox
- Full CRUD functionality
- RESTful API and MVC architecture

---

## 🛠 Tech Stack

### Frontend

- CSS3

### Backend
- Node.js
- Express

- MongoDB

### Services & APIs

### Tools & Other

- MVC Architecture

## ⚙️ Installation & Setup

1. Clone the repository:
2. Install dependencies: npm install
3. Create a .env file and add the following: MONGO_URL=your_mongodb_connection_string
MAPBOX_TOKEN=your_mapbox_token
CLOUDINARY_CLOUD_NAME=your_cloudinary_name
CLOUDINARY_KEY=your_cloudinary_key
CLOUDINARY_SECRET=your_cloudinary_secret
SESSION_SECRET=your_session_secret
4. Run the application: npm start
5. Open your browser: http://localhost:3000
